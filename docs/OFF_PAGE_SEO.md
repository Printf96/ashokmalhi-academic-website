# Off-Page SEO Readiness

This build cannot create external backlinks — that requires real-world
academic and professional activity. What it does is make the site
**ready** to accumulate legitimate off-page signals, and documents the
concrete next actions.

## What's already in place

- **Canonical, stable URLs** for every page and every publication
  (`/publications/:slug`), suitable for citing from external profiles.
- **Consistent `sameAs` linking** from the site to ORCID, Scopus,
  Google Scholar, ResearchGate, LinkedIn, Facebook, and Instagram
  (see docs/TECHNICAL_SEO.md), so those platforms and the official site
  reinforce the same entity.
- **`rel="me"`** on academic/professional profile links
  (`AcademicProfilesList`), a lightweight but real identity-verification
  signal some indexers respect.
- **Author bio placeholder** on the About page, ready to receive a full
  biography for use as consistent author-bio text across guest posts,
  conference bios, and directory listings.
- **Shareable, citation-friendly publication URLs** with breadcrumb and
  `ScholarlyArticle` structured data, appropriate to paste into a CV,
  ORCID works list, or departmental page.

## Recommended future actions (manual, off-platform)

1. **ORCID**: Add `https://ashokmalhi.pro` as the personal website/URL
   field on the ORCID profile; ensure ORCID's public works list
   references the same publication titles used here.
2. **Google Scholar**: Add the official website URL to the Scholar
   profile's homepage field.
3. **ResearchGate**: Link the official website from the ResearchGate
   profile's website field; ensure the institutional affiliation string
   matches exactly ("Lovely Professional University").
4. **LinkedIn**: Add `ashokmalhi.pro` under Contact Info → Website;
   ensure the current position matches "Assistant Professor, Lovely
   Professional University" exactly.
5. **Institutional profile**: Request that the Lovely Professional
   University faculty directory page link to the official website, if
   not already present — an institutional backlink is one of the
   highest-value legitimate signals available.
6. **Conference / publication platforms**: When submitting future
   papers, use the official website URL in the author information
   field where the venue allows it.
7. **Academic directories**: Consider legitimate, free academic
   directory listings (e.g. institutional faculty pages, subject-area
   society directories) — never paid link farms or link-exchange
   schemes.
8. **Citations**: Encourage citing authors to link the DOI/URL when
   available; once DOIs are added to the Publication records here
   (docs/CONTENT_UPDATE_GUIDE.md), each detail page's `doi` field will
   surface a working `https://doi.org/...` link automatically.

## What this project will never do

Per brief sections 26 and 49: no spam backlinks, no link farms, no
paid link schemes, no fake reviews or testimonials, no reciprocal-link
schemes designed purely to manipulate rankings. Off-page growth here
means real academic and professional activity, reflected accurately.
